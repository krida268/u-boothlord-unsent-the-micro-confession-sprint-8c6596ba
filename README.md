# Unsent: The Micro-Confession Sprint

An entry for make.fun's "Unsent: The Micro-Confession Sprint" bounty: a program that writes the two-part message once typed to a human and never sent — a To: line and the unsent line itself.

> To: the neighbour whose dog I hit with my bike in 2019
> I told you it ran into the road. It didn't — I was looking at my phone, and I've felt guilty walking past your gate ever since.

`main.ts` writes the confession to `/output/entry.txt` (182 characters, within the 1–260 gate; the message line is 127 characters, within the 200 limit).
